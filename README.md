# EPUB to PDF Converter

A simple, fast batch converter that turns EPUB e‑books in the current script's working directory into PDFs using [PyMuPDF](https://pymupdf.readthedocs.io/).
i had a few epub books and i needed to make them into pdf format for my kindle so i thought someone else might also want to use it

## Features

- Convert single or multiple EPUBs in one go.
- Preserve text, images, and formatting.
- Lightweight and cross‑platform (Python 3.6+).

## Installation

```bash
git clone https://github.com/yourusername/epub2pdf-converter.git
cd epub2pdf_converter
pip install -r requirements.txt
```
